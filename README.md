# Bashar & Bayan — Animated Engagement Invitation

Open `index.html` in a modern browser. Keep the `assets` folder beside it.
The invitation opens with an animated envelope, then reveals the supplied invitation artwork with a gold shimmer, falling petals, countdown, and working Google Maps links.

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html`, `README.md`, and the complete `assets` folder to the repository root.
3. Open Settings → Pages.
4. Choose Deploy from a branch → `main` → `/(root)` → Save.
5. Wait for GitHub Pages to publish the site.

Countdown target: 08 December 2026, 5:30 PM Amman time (UTC+03:00).
